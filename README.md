# bootybounce

A tiny desktop pet. It sits on your desktop, chills in the background and does a little booty bounce on loop.

Not a GIF: the animation is drawn in code, so it stays sharp at any size and can react to things.

## Idea

- borderless, transparent window, only the pet is visible
- sits on the taskbar, clicks go through everywhere except the pet
- drag it somewhere else and it stays there
- bounces on loop, sometimes sits down and chills
